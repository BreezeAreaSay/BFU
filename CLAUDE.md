# CLAUDE.md

Контекст для Claude Code при работе с этим репозиторием.

## Как работаем

- Решения пишем на Python 3.
- Готовый код всегда даём прямо в чате, целиком: пользователь копирует его оттуда.
- Каждая задача — в своей папке: `<название-задачи>/solution.py` (например, `moves/solution.py`).
- Стиль — PEP 8, проверяем `flake8`: система проверяет качество кода перед компиляцией (вердикт PCF).
- Перед тем как отдать решение, прогоняем его на примерах из условия.

## Вердикты тестирующей системы

Пользователь сдаёт решения в тестирующую систему; по её вердикту ищем ошибку.
«Значение» — по справке системы, «Что проверить» — с чего начинать поиск.

| Вердикт | Сообщение | Номер теста | Значение | Что проверить |
|---|---|:---:|---|---|
| CE | Compilation error | — | Программа не скомпилировалась. | Синтаксические и семантические ошибки; правильно ли выбран язык при отправке. |
| IL | Idleness limit exceeded | ✓ | Программа слишком долго не отвечала системе и ничего не делала. | Не ждёт ли программа ввода, которого нет; вызван ли `flush()` после вывода (особенно в интерактивных задачах). |
| ML | Memory limit exceeded | ✓ | Превышен лимит памяти. | Слишком большие массивы и структуры данных; бесконечная рекурсия. |
| OK | OK | — | Решение зачтено: программа верно работает на всём наборе тестов. | — |
| OL | Output limit exceeded | ✓ | Программа выводит больше, чем разрешено ограничениями. | Отладочный вывод; печать в бесконечном цикле. |
| PCF | Precompile check failed | — | Код не прошёл проверку качества перед компиляцией. | Качество и форматирование кода. |
| PE | Presentation error | ✓ | Формат вывода не соответствует условию, система не может проверить ответ. | Формат вывода по условию; печатается ли результат вообще; нет ли лишнего вывода (отладка, подсказки вроде «Введите число»). |
| RE | Run-time error | ✓ | Программа завершилась с ненулевым кодом возврата. | Необработанные исключения, выход за границы массива, деление на ноль; `return 0` в `main` (C/C++); явный ненулевой код выхода; Java-класс не должен быть объявлен в пакете (`package`). |
| TL | Time-limit exceeded | ✓ | Превышен лимит времени. | Сложность алгоритма; бесконечный цикл; медленный ввод-вывод. |
| WA | Wrong answer | ✓ | Неверный ответ на одном из тестов. | Примеры из условия; граничные случаи (минимальные и максимальные данные); переполнение типов. |

Номер теста система сообщает для всех вердиктов, кроме OK, CE и PCF: при CE и PCF
ошибка возникает ещё до начала тестирования.
